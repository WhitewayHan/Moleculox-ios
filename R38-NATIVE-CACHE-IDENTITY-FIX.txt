MOLECULOX iOS V8.5.78 R38 — NATIVE ASSET CACHE IDENTITY FIX

Observed TestFlight symptom
- Cloud progress had a current successful-sync timestamp and ranking reads worked.
- The panel still showed the pre-R36 text “Sign-in could not be completed … [permission-denied]”.

Root cause
- R37's index.html still requested CSS with an R25 query token and all runtime
  JavaScript with the R24 query token.
- WKWebView could therefore reuse an older cached game.js/firebase.js after the
  TestFlight update, bypassing the R32–R37 sync/error fixes shipped in the bundle.

Fix
- Every mutable CSS/JavaScript reference now uses the unique
  8.5.78-r38-native-cache-bust token.
- App, package, manifest, service-worker, Xcode and Codemagic versions are aligned.
- A regression test fails the build if a stale R24/R25 token returns or any
  release identity diverges.

R37 account-context and manual-sync protections remain unchanged.
