CLAUDE HANDOFF — R10 PLATFORM CSS ISOLATION

Problem confirmed from iOS-vs-Web visual analysis:
Capacitor.isNativePlatform() returns true on both iOS and Android. Visual overrides under body.mxNative therefore leaked iOS WKWebView-specific pixel values into Android.

Implemented correction:
- MX_NATIVE remains the shared native-runtime flag for functional behavior.
- MX_IOS_NATIVE and MX_ANDROID_NATIVE remain based on Capacitor.getPlatform().
- Body now receives mxIOSNative and mxAndroidNative classes in addition to mxNative/mxWeb.
- Every visual selector in the R7-R9 override block now uses body.mxIOSNative.
- Android receives no iOS visual override and falls back to the approved Web/Android base CSS.
- .iosStandalone was deliberately not changed because it predates these patches and supports iOS PWA/native full-screen layouts.

Do not replace mxIOSNative with mxNative in the visual override block.
