MOLECULOX iOS V8.5.54 R7 FINAL

APPLE SIGN-IN
- Removed the custom JS-to-native nonce injection used in R3-R6.
- The official native plugin is now the only nonce generator.
- Native sends SHA-256(raw nonce) to Apple and returns the exact raw nonce in credential.nonce.
- JavaScript verifies SHA-256(returned raw nonce) against the signed nonce claim in the Apple ID token before Firebase credential creation.
- Safe stage-only diagnostics are retained locally and in the device console; tokens and nonce values are never logged.

OWNER PROFILE
- Successful sign-in with the confirmed owner Google or Hotmail address is normalized to the visible player name wHiTeWaY.
- The Firebase Auth display name and the active cloud profile name are both updated.
- Apple sign-in on a device that already has a local wHiTeWaY identity keeps the same visible player identity.
- Campaign progress is not required for this naming normalization.
