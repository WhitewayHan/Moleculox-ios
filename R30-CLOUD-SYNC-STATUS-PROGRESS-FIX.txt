Moleculox iOS V8.5.70 R30

Fixes:
1. Keeps campaign progress monotonic when an older cloud snapshot arrives after newer local completions.
2. Journals the newest progress locally and queues a retry before iOS suspension/pagehide.
3. Fixes the false red "Sync error" state caused when rapid local saves cancelled an older debounce timer. Superseded save callers now wait for the newest real Firestore result instead of being resolved as failures.
4. Preserves safe handling when switching profiles by flushing a pending save for the previous profile.

Observed R28 symptom explained:
- Authentication and leaderboard reads could succeed.
- The panel could still show Sync error because a superseded autosave returned false locally.
- This affected email/Google/Apple equally because it was shared sync code, not an authentication-provider failure.
