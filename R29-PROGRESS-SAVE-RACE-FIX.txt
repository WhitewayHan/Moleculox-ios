MOLECULOX iOS V8.5.70 R29 — PROGRESS SAVE RACE FIX

Observed defect
- Player reached level 59, closed/reopened iOS app, and Continue returned to level 56.

Root cause
- Local completion was persisted immediately, but delayed cloud transaction results were applied as fully authoritative for permanent accounts.
- A stale level-56 cloud response could therefore replace newer local level-59 progress before the newest checkpoint finished.
- iOS suspension could terminate the remaining network write.

Fixes
1. Cloud/local profile application is monotonic for campaign progress (max level, max stars, union discoveries/achievements, best records).
2. Delayed cloud responses can no longer lower current local progress.
3. Every completed-level checkpoint is journaled locally even while Firebase Auth is restoring.
4. visibility-hidden and pagehide persist the newest local profile and retryable cloud checkpoint before WKWebView suspension.
5. Regression verification added to npm run check.

Release handling
- This is a replacement build for the currently submitted R28 binary.
- Keep CFBundleShortVersionString 8.5.70; Codemagic generates a new unique timestamp CFBundleVersion.
